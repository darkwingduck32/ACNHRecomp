# 360 Camera

The current implementation is a versioned feature package, with a matching player
module and reviewed models/profiles. See [package documentation](../../features/camera/README.md)
for building, installation, compatibility and rebasing.

The legacy empty-RomFS marker folder remains supported for existing local setups.
It is not the complete distributable feature. Current controls are right-stick
orbit, hold R3 plus vertical stick to zoom, tap R3 to reset; keyboard F6 plus I/K
to zoom and F7 to reset. Interiors and active UI keep their native controls.
